# JavaScript Web Development Internship - EWB

Assignments 1-6 and the Capstone Mini Project: **Interactive Product Inventory & Analytics Dashboard**.

## Structure
- `assignments/` - assignment1.js to assignment6.js
- `project/script.js` - mini project
- `index.html` - run everything in the browser

## How to run
Open `index.html` through a local server (e.g. VS Code "Live Server") and click a button, or enable GitHub Pages.
Prompts (`prompt()`) appear as browser pop-ups.
